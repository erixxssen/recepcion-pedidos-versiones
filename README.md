# Versiones publicadas

Este repositorio solo guarda las versiones publicadas de una herramienta interna, para que las PCs donde está instalada se actualicen solas.

- Cada versión es un paquete **cifrado** y un manifiesto **firmado**. Sin las claves, el paquete no sirve para nada, y la herramienta solo instala versiones con la firma correcta.
- **No contiene código fuente.**
